# Currency Converter — Privacy Policy

A lightweight privacy-policy page for Currency Converter by Elabboubi Solution.

## Before publishing

1. Edit `index.html` and replace **every** `[BRACKETED PLACEHOLDER]` with accurate information.
2. Verify the exchange-rate API provider, all SDKs, locally stored data, target audience, and contact email against the actual release build.
3. Make sure the policy matches the Google Play Data safety form and actual AdMob/UMP configuration.
4. Check that the page's third-party links work, including the exchange-rate provider's privacy policy.

## Publish with GitHub Pages

1. Create a **public** repository named `currency-converter-privacy` under `hamzaelabboubi`.
2. Upload `index.html` (and optionally this README) to the repository root on `main`.
3. Go to **Settings → Pages → Build and deployment** and choose **Deploy from a branch**, `main`, `/ (root)`, then **Save**.
4. Wait for the deployment and visit `https://hamzaelabboubi.github.io/currency-converter-privacy/`.
5. Once the page works and the content is accurate, use that URL in AdMob and Play Console.

This is a draft template, not a legal compliance guarantee.
